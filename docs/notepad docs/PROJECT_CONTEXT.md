## Project idea
Memory Hub is a web-based personal memory system.

The user can save important personal information:
- notes
- ideas
- tasks
- events
- links
- files
- study materials
- project information

The goal is to make information easier to store, find, and understand.

## Problem
A person receives a lot of information every day.
This information is often spread across different places:
messengers, notes, files, browser tabs, university materials, and personal documents.

Because of this, useful information is lost or hard to find later.

## Proposed solution
Memory Hub provides one interface where the user can collect and organize personal information.

The prototype demonstrates:
- adding memories
- viewing a library of saved memories
- searching information
- viewing memories on a timeline
- opening memory details
- using tags and categories
- using a mock AI assistant
- using a visual graph / memory map
- changing settings

## Current implementation
The current version is a frontend prototype.

Implemented with:
- React
- Vite
- JavaScript
- Tailwind CSS
- React Router
- LocalStorage

Data is stored locally in the browser using LocalStorage.

AI functions are mocked to show the concept.

## Why this is enough for current ВКР stage
The main task of the student is frontend development.
The prototype shows the user interface, user flow, navigation, and main modules.

Backend, database, real AI/NLP, semantic vector search, and cloud storage are possible future development directions.
