## Main goal
Develop a frontend prototype of an intelligent personal memory system called Memory Hub.

The system helps a user save personal information such as notes, tasks, links, files, events, and ideas.
The interface should demonstrate how the user can later search, organize, and understand this personal information.

## Important academic focus
The current ВКР focuses on frontend development:
- UI/UX design
- React application structure
- navigation
- pages and modules
- LocalStorage persistence
- search interface
- timeline view
- graph visualization
- AI Chat mock
- settings page
- video demo support

Do not focus on backend, database, or real AI integration unless the task explicitly asks for it.
Backend, database, vector search, and real AI/NLP can be described as future development.

Before changing code:
- inspect existing structure

- avoid rewriting the whole project from zero

- preserve working functionality
- run build or explain why it cannot be run

When implementing:
- use existing components and style

- avoid changing project architecture without need
